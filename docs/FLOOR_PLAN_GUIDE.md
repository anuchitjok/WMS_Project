# คู่มือ Floor Plan (ผังคลังสินค้า)

> เมนู **Warehouse Operations** → แท็บ **Floor Plan**
> มีเวอร์ชันจัดหน้าสวย เปิดอ่านง่ายกว่าที่ [`FLOOR_PLAN_GUIDE.html`](./FLOOR_PLAN_GUIDE.html) (ดับเบิลคลิกเปิดในเบราว์เซอร์ได้เลย)

เขียนจากจุดที่คนใช้งานติดจริง ไม่ใช่ไล่อธิบายทีละปุ่ม

---

## A. เข้าใจ 2 ชั้นนี้ก่อน แล้วที่เหลือง่ายหมด

**ถ้ายังงงข้อความ `A rack links to a rack` — อ่านหัวข้อนี้หัวข้อเดียวพอ**

ระบบมีของอยู่ 2 ชั้น ที่ชื่อซ้ำกันจนสับสน:

| ชั้น | คืออะไร | สร้างที่ไหน |
|---|---|---|
| **ชั้นผัง (Floor Plan)** | กล่องที่คุณวาด บอกว่า "ของตั้งอยู่ตรงไหนบนพื้น" | หน้านี้ |
| **ชั้น WMS** | Rack / Slot ของจริงที่มีสต็อกอยู่ข้างใน | เมนู Warehouse Master |

**กล่องที่วาดใหม่ ๆ มันว่างเปล่า** — ไม่รู้จักสต็อกใด ๆ จนกว่าคุณจะ **ผูก (Link)** มันเข้ากับของจริง

ดังนั้นข้อความ `A rack links to a rack` จริง ๆ แปลว่า
**"กล่อง Rack ที่คุณวาด" ต้องผูกกับ "Rack จริงใน WMS"** — คนละ rack กัน

```
ชั้นผัง (คุณวาด)              ชั้น WMS (ของจริง)
┌──────────────┐   ผูก      ┌──────────────┐
│ กล่อง Bin A-01│ ─ ─ ─ ─ ─> │  Slot A-01   │
│ ตำแหน่ง x,y,w,h│            │  รหัส · ความจุ │
└──────────────┘            └──────┬───────┘
       │                           │ อยู่ใน
       │ ตัวเลข Available/Committed  ▼
       └────── อ่านสดจาก ─────> ┌──────────────┐
                                │  StockItem   │
                                └──────────────┘
```

ผัง **ไม่เคยเก็บจำนวนของไว้เลย** ทุกครั้งที่เปิดหน้ามันไปอ่านจาก WMS ใหม่
— นี่คือเหตุผลที่ตัวเลขไม่มีวันค้างไม่ตรงกับของจริง

---

## B. ทำครั้งแรก ทีละขั้น

1. **เลือกคลังก่อน** — กดการ์ดคลังในแถบ *Storage Utilization by Warehouse* ด้านบน ผังจะผูกกับคลังที่เลือกอยู่
2. **กด `Create floor plan`** — ครั้งแรกจะยังว่าง เพราะระบบสร้างแค่ที่ว่างไว้ให้ (ปุ่มนี้เห็นเฉพาะ Admin กับ Manager)
3. **กด `Edit layout`** — แถบเครื่องมือจะโผล่ขึ้นมา พร้อมชุดปุ่ม *Add object*
4. **วางกล่องจากแถบ Add object** — กดชื่อประเภทที่ต้องการ กล่องจะวางลงผังให้เลย แล้วค่อยลากไปตำแหน่งที่ถูก ย่อ-ขยายด้วยจุดที่มุม
5. **เลือกกล่อง Rack แล้วกด `Link location`** — เลือก Rack จริงจากรายการ
   **ขั้นนี้คือขั้นที่คนติดมากที่สุด** ถ้าไม่ผูก กล่องจะไม่มีตัวเลขอะไรเลยตลอดไป
6. **กด `Draw bins from slots`** — ระบบจะวาด bin ให้อัตโนมัติทุกช่องที่ Rack นั้นมีอยู่จริง พร้อมผูกให้เสร็จ ไม่ต้องวาดทีละช่อง
7. **กด `Save`** — บันทึกทีเดียวทั้งชุด ไม่ได้ยิงทุกครั้งที่ลาก ถ้ายังไม่กดจะมีคำว่า *Unsaved changes* เตือนอยู่

> ⚠️ ถ้ายังไม่ได้ผูก Rack กับของจริง ปุ่ม `Draw bins from slots` **จะไม่ขึ้น** — ทำขั้น 5 ให้เสร็จก่อนเสมอ

## C. อะไรผูกได้ อะไรผูกไม่ได้

| ประเภทกล่อง | ผูกกับ | มีตัวเลขสต็อกมั้ย |
|---|---|---|
| **Bin** | Slot ใน WMS | ✅ มี — ตัวหลักที่ใช้ดูของ |
| **Rack** | Rack ใน WMS | ✅ ผูกเพื่อใช้ปุ่มวาด bin อัตโนมัติ |
| Zone, Aisle, Shelf | ผูกไม่ได้ | ไม่มี |
| Receiving, Shipping, Staging, QC, Work, Custom | ผูกไม่ได้ | ไม่มี |

พื้นที่รับของ พื้นที่ QC ทางเดิน — พวกนี้ไม่มีคู่ใน WMS อยู่แล้ว
มันมีไว้ให้คนดูผังเข้าใจว่าอะไรอยู่ตรงไหน ไม่ได้มีไว้เก็บของในระบบ

## D. อ่านสีกับตัวเลขให้ออก

### สีของ bin = ความแน่น

| สี | ความแน่น | หมายถึง |
|---|---|---|
| เขียวอ่อน | ว่าง | ไม่มีของเลย |
| เขียว | ต่ำกว่า 30% | ยังรับได้อีกเยอะ |
| เหลือง | 30–59% | ปกติ |
| ส้ม | 60–89% | เริ่มแน่น |
| แดง | 90% ขึ้นไป | เต็ม |

ใช้มาตรฐานเดียวกับ heatmap ในแท็บ **Control Center** — สีเดียวกันแปลว่าเหมือนกัน

### ตัวเลขในแผงขวา

| ช่อง | ความหมาย |
|---|---|
| **Available** | ของที่หยิบไปใช้ได้จริงตอนนี้ |
| **Committed** | ของที่ยังอยู่ในช่อง แต่ถูกจองไว้แล้ว (กำลังจัด / แพ็ค / รอส่ง) |
| **Total Quantity** | รวมทั้งหมดในช่อง |
| **SKU Count** | จำนวนรหัสสินค้าที่ต่างกันในช่องนั้น |
| **Utilization** | จำนวนชิ้น ÷ ความจุของช่อง |

> ⚠️ **ยังไม่ยืนยัน — ช่วยเช็คให้หน่อยตอนใช้ครั้งแรก**
>
> **Available** กับ **Committed** ยังไม่เคยถูกตรวจกับข้อมูลจริง
> ระบบไม่มีคอลัมน์เก็บค่านี้ไว้ตรง ๆ ต้องคำนวณจากสถานะของสต็อก
>
> เปิด bin ที่ผูกแล้ว จำเลขไว้ → ไปแท็บ **Control Center** ดูช่องเดียวกัน → **ตรงกันมั้ย**
> ถ้าไม่ตรง แจ้งทีมพัฒนาได้ทันที

## E. ข้อมูลอัปเดตเองแค่ไหน

| อะไร | อัปเดตเอง? |
|---|---|
| ตัวเลขสต็อก + สีของ bin | ✅ อัตโนมัติ ไม่ต้องกดอะไร |
| เพิ่ม Rack ใหม่ใน Warehouse Master | ❌ ไม่ขึ้นเอง ต้องมาวาด + ผูกเอง |
| เพิ่ม Slot ใน Rack ที่ผูกแล้ว | ❌ กด `Draw bins from slots` ซ้ำ (ข้ามอันเดิมให้) |
| ลบ Slot ทิ้ง | ❌ bin จะโดนขีดฆ่า + ขึ้นแถบเตือน ไม่หายเอง |

**สรุป: ของข้างในกล่อง sync เอง · ตัวกล่องต้องจัดการเอง**

### เช็คว่า realtime ทำงานมั้ย

ให้คนอื่นทำ putaway หรือรับของเข้า bin ที่เปิดดูอยู่:

- สีเปลี่ยนใน **1–2 วินาที** → ต่อ realtime ติด
- สีเปลี่ยนภายใน **1 นาที** → realtime ไม่ติด กำลังใช้ตัวสำรอง (ยังถูกต้อง แค่ช้ากว่า)

*หมายเหตุ: ตอนนี้ยังไม่มีไฟบอกสถานะบนหน้าจอ ต้องดูจากอาการเอา*

## F. เจอปัญหาแบบนี้ ทำยังไง

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `Not linked. A rack links to a rack…` | กล่องยังไม่ได้ผูก — กด `Link location` ในแผงเดียวกันแล้วเลือก Rack จริง |
| เลือก bin แล้วไม่มีตัวเลขสต็อก | bin ยังไม่ผูก Slot · ถ้าวาดเองต้องผูกเอง หรือใช้ `Draw bins from slots` ซึ่งผูกให้อัตโนมัติ |
| รายการ Slot ขึ้นว่า *already drawn* กดไม่ได้ | Slot นั้นมีกล่องอื่นบนผังจับจองไว้แล้ว — 1 Slot ผูกได้กล่องเดียว หาอันเดิมแล้ว unlink ก่อน |
| bin มีเส้นขีดทับ + แถบเหลืองเตือน | Slot ที่ผูกไว้ถูกลบไปแล้วใน Warehouse Master — ผูกใหม่กับ Slot อื่น หรือลบกล่องทิ้ง |
| กด Save แล้วขึ้น *changed elsewhere* | มีคนอื่นบันทึกผังนี้ระหว่างที่คุณแก้อยู่ ระบบไม่ทับของเขาให้ — กด `Refresh` แล้วแก้ใหม่ |
| ไม่เห็นปุ่ม `Edit layout` / `Create floor plan` | สิทธิ์ไม่ถึง — แก้ผังได้เฉพาะ Admin กับ Manager · ถ้าเปิดบนมือถือก็จะไม่มีเช่นกัน (มือถือดูอย่างเดียว) |
| Supervisor / Staff สร้าง Rack ไม่ได้แล้ว | ตั้งใจแก้ — เมื่อก่อน API ไม่เช็คสิทธิ์เลย ใครก็สร้าง/ลบ rack ได้ ตอนนี้ปิดช่องโหว่แล้ว ให้ Manager เป็นคนสร้าง |
| ลากแล้วกล่องกระโดดเป็นช่อง ๆ | Snap เปิดอยู่ (ตั้งใจ) — กดปุ่ม `Snap` ในแถบเครื่องมือเพื่อปิด ถ้าอยากวางอิสระ |

## G. ทางลัดตอนแก้ผัง

| ปุ่ม | ทำอะไร |
|---|---|
| `Ctrl` + `Z` | ย้อนกลับ |
| `Ctrl` + `Shift` + `Z` | ทำซ้ำ |
| `Ctrl` + `D` | ทำสำเนากล่องที่เลือก |
| `Ctrl` + `S` | บันทึก |
| `Delete` | ลบกล่องที่เลือก |
| `Esc` | ยกเลิกการเลือก |
| `Shift` + ลากบนพื้นที่ว่าง | ลากคลุมเลือกหลายกล่อง |
| `Shift` + คลิกกล่อง | เพิ่ม/เอาออกจากที่เลือกไว้ |
| ลากพื้นที่ว่าง | เลื่อนผัง · หมุนล้อเมาส์ = ซูม |

สำเนาที่ได้จาก `Ctrl`+`D` **จะไม่ติดการผูกมาด้วย** เพราะ 1 Slot ผูกได้กล่องเดียว ต้องผูกใหม่เอง

## H. สิ่งที่ยังทำไม่ได้

- **สั่งงานจากผังไม่ได้** — ย้ายของ บล็อกช่อง สั่งนับ ยังต้องทำที่ Control Center / Inventory / Transfer เหมือนเดิม ผังนี้ดูอย่างเดียว
- **หมุนกล่องไม่ได้** — ยังไม่มีปุ่ม (ค่าหมุนรองรับแล้วในระบบ แค่ยังไม่มีที่ให้กด)
- **ไม่มีไฟบอกว่าข้อมูลสดหรือค้าง**
- **ผังไม่ดึงโครงสร้างใหม่มาให้เอง** — เพิ่ม Rack แล้วต้องมาวาดเอง
