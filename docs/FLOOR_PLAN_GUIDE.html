คู่มือ Floor Plan

วิธีสร้างผังคลังจริง ผูกเข้ากับ WMS แล้วอ่านค่าให้ออก — เขียนจากจุดที่คนติดจริง ไม่ใช่ไล่ทีละปุ่ม

Aเข้าใจ 2 ชั้นนี้ก่อน แล้วที่เหลือง่ายหมด

ถ้ายังงงข้อความ “A rack links to a rack” — อ่านหัวข้อนี้หัวข้อเดียวพอ

หัวใจ

กล่องบนผัง = รูปวาด ไม่ใช่ของจริง

ระบบมีของอยู่ 2 ชั้น ที่ชื่อซ้ำกันจนสับสน:

  • ชั้นผัง (Floor Plan) — กล่องที่คุณวาด บอกว่า “ของตั้งอยู่ตรงไหนบนพื้น”
  • ชั้น WMS — Rack / Slot ของจริงที่มีสต็อกอยู่ข้างใน (สร้างที่เมนู Warehouse Master)

กล่องที่วาดใหม่ ๆ มัน ว่างเปล่า — ไม่รู้จักสต็อกใด ๆ จนกว่าคุณจะ ผูก (Link) มันเข้ากับของจริง

ดังนั้นข้อความ A rack links to a rack จริง ๆ แปลว่า:
“กล่อง Rack ที่คุณวาด ต้องผูกกับ Rack จริงใน WMS” — คนละ rack กัน

Bทำครั้งแรก ทีละขั้น

เมนูซ้าย → Warehouse Operations → แท็บ Floor Plan

  1. เลือกคลังก่อน
    กดการ์ดคลังในแถบ Storage Utilization by Warehouse ด้านบน ผังจะผูกกับคลังที่เลือกอยู่
  2. กด Create floor plan
    ครั้งแรกจะยังว่าง เพราะระบบสร้างแค่ที่ว่างไว้ให้ ยังไม่มีผัง — ปุ่มนี้เห็นเฉพาะ Admin กับ Manager
  3. กด Edit layout
    แถบเครื่องมือจะโผล่ขึ้นมา พร้อมชุดปุ่ม Add object
  4. วางกล่องจากแถบ Add object
    กดชื่อประเภทที่ต้องการ กล่องจะวางลงผังให้เลย แล้วค่อยลากไปตำแหน่งที่ถูก · ย่อ-ขยายด้วยจุดที่มุม
  5. เลือกกล่อง Rack แล้วกด Link location
    เลือก Rack จริงจากรายการ — ขั้นนี้แหละที่คุณติดอยู่ ถ้าไม่ผูก กล่องจะไม่มีตัวเลขอะไรเลยตลอดไป
  6. กด Draw bins from slots
    ระบบจะวาด bin ให้อัตโนมัติทุกช่องที่ Rack นั้นมีอยู่จริง พร้อมผูกให้เสร็จ — ไม่ต้องวาดทีละช่อง
  7. กด Save
    ระบบบันทึกทีเดียวทั้งชุด ไม่ได้ยิงทุกครั้งที่ลาก · ถ้ายังไม่กด จะมีคำว่า Unsaved changes เตือนอยู่
ระวัง

ถ้ายังไม่ได้ผูก Rack กับของจริง ปุ่ม Draw bins from slots จะไม่ขึ้น — ทำขั้น 5 ให้เสร็จก่อนเสมอ

Cอะไรผูกได้ อะไรผูกไม่ได้

ผูกได้แค่ 2 ประเภท ที่เหลือคือรูปวาดล้วน ๆ — ตั้งใจให้เป็นแบบนั้น

ประเภทกล่องผูกกับมีตัวเลขสต็อกมั้ย
BinSlot ใน WMSมี — ตัวหลักที่ใช้ดูของ
RackRack ใน WMSผูกเพื่อใช้ปุ่มวาด bin อัตโนมัติ
Zone, Aisle, Shelfผูกไม่ได้ไม่มี
Receiving, Shipping, Staging, QC, Work, Customผูกไม่ได้ไม่มี

พื้นที่รับของ พื้นที่ QC ทางเดิน — พวกนี้ไม่มีคู่ใน WMS อยู่แล้ว มันมีไว้ให้คนดูผังเข้าใจว่าอะไรอยู่ตรงไหน ไม่ได้มีไว้เก็บของในระบบ

เปิด bin ที่ผูกแล้ว จำเลขไว้ → ไปแท็บ Control Center ดูช่องเดียวกัน → ตรงกันมั้ย ถ้าไม่ตรง บอกได้เลย

Eข้อมูลอัปเดตเองแค่ไหน

อะไรอัปเดตเอง?
ตัวเลขสต็อก + สีของ binอัตโนมัติ ไม่ต้องกดอะไร
เพิ่ม Rack ใหม่ใน Warehouse Masterไม่ขึ้นเอง ต้องมาวาด + ผูกเอง
เพิ่ม Slot ใน Rack ที่ผูกแล้วกด Draw bins from slots ซ้ำ (ข้ามอันเดิมให้)
ลบ Slot ทิ้งbin จะโดนขีดฆ่า + ขึ้นแถบเตือน ไม่หายเอง

สรุป: ของข้างในกล่อง sync เอง · ตัวกล่องต้องจัดการเอง

เช็คว่า realtime ทำงานมั้ย: ให้คนอื่นทำ putaway หรือรับของเข้า bin ที่เปิดดูอยู่

  • สีเปลี่ยนใน 1–2 วินาที → ต่อ realtime ติด
  • สีเปลี่ยนภายใน 1 นาที → realtime ไม่ติด กำลังใช้ตัวสำรอง (ยังถูกต้อง แค่ช้ากว่า)

หมายเหตุ: ตอนนี้ยังไม่มีไฟบอกสถานะบนหน้าจอ ต้องดูจากอาการเอา

อาการสาเหตุ / วิธีแก้
Not linked. A rack links to a rack… กล่องยังไม่ได้ผูก — กด Link location ในแผงเดียวกันแล้วเลือก Rack จริง

รายการ Slot ขึ้นว่า already drawn กดไม่ได้ Slot นั้นมีกล่องอื่นบนผังจับจองไว้แล้ว — 1 Slot ผูกได้กล่องเดียว หาอันเดิมแล้ว unlink ก่อน
bin มีเส้นขีดทับ + แถบเหลืองเตือน Slot ที่ผูกไว้ถูกลบไปแล้วใน Warehouse Master — ผูกใหม่กับ Slot อื่น หรือลบกล่องทิ้ง
กด Save แล้วขึ้น changed elsewhere มีคนอื่นบันทึกผังนี้ระหว่างที่คุณแก้อยู่ ระบบไม่ทับของเขาให้ — กด Refresh แล้วแก้ใหม่

Supervisor / Staff สร้าง Rack ไม่ได้แล้ว ตั้งใจแก้ — เมื่อก่อน API ไม่เช็คสิทธิ์เลย ใครก็สร้าง/ลบ rack ได้ ตอนนี้ปิดช่องโหว่แล้ว ให้ Manager เป็นคนสร้าง
ลากแล้วกล่องกระโดดเป็นช่อง ๆ Snap เปิดอยู่ (ตั้งใจ) — กดปุ่ม Snap ในแถบเครื่องมือเพื่อปิด ถ้าอยากวางอิสระ

Hสิ่งที่ยังทำไม่ได้

บอกไว้ก่อน จะได้ไม่เสียเวลาหา

  • สั่งงานจากผังไม่ได้ — ย้ายของ บล็อกช่อง สั่งนับ ยังต้องทำที่ Control Center / Inventory / Transfer เหมือนเดิม ผังนี้ดูอย่างเดียว
  • หมุนกล่องไม่ได้ — ยังไม่มีปุ่ม (ค่าหมุนรองรับแล้วในระบบ แค่ยังไม่มีที่ให้กด)
  • ไม่มีไฟบอกว่าข้อมูลสดหรือค้าง
  • ผังไม่ดึงโครงสร้างใหม่มาให้เอง — เพิ่ม Rack แล้วต้องมาวาดเอง
